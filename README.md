# CURS

Веб-панель для сравнения официального курса ЦБ РФ с рыночным индикатором LiveExchanges для USD/RUB, EUR/RUB и CNY/RUB.

Актуальная версия: **0.1**.

## Обновление данных

- Рыночный индикатор обновляется каждую минуту, пока вкладка открыта.
- История рыночного курса загружается один раз при открытии страницы или смене валюты.
- Данные ЦБ РФ проверяются при открытии и затем раз в 6 часов.
- В скрытой вкладке автообновление приостанавливается.

## Источники

- Официальный курс: [Банк России](https://www.cbr.ru/currency_base/daily/) через `cbr-xml-daily.com`.
- Рыночный индикатор: [LiveExchanges](https://www.liveexchanges.com/markets).
- Рыночная история: `@fawazahmed0/currency-api` через jsDelivr.

Рыночные значения являются индикативными. При недоступности источника индикатор `LIVE` меняется на `НЕТ ДАННЫХ`.
